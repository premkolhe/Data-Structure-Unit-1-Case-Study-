# E-commerce Product Sorting and Calendar Scheduling
A Python case study demonstrating two algorithm design strategies:

- **Divide and Conquer:** Merge Sort to sort e-commerce products by price.
- **Greedy strategy:** Interval scheduling to select the maximum number of non-overlapping calendar events.

## Features

- Sort products from lowest to highest price.
- Display product names, prices, and ratings.
- Choose a maximum-size set of non-overlapping calendar events.
- Display the selected events in schedule order.

## Requirements

- Python 3.7 or newer

No external packages are required.
